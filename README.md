# «ПРИЁМ» — прототип симулятора логопедического обследования

Мобильное веб-приложение для отработки алгоритма логопедического приёма и дифференциальной
диагностики у детей 4–7 лет. Основа — российская логопедическая школа (Левина, Филичева, Чиркина,
Волкова), с международной рамкой МКБ-10/МКБ-11 и практиками ASHA.

Полный концепт и дизайн — в [DESIGN.md](DESIGN.md).

**Живая демо-версия:** https://naumovalexey-dev.github.io/logoped_learn/

**Словарь терминов:** 40 сокращений и понятий — кнопка «Словарь» в шапке, вкладка «Теория → Словарь» и кнопка в обучении.

## Что уже работает

- **Два playable-кейса:** дислалия (Федя, 6 лет) и дизартрия, стёртая форма (Настя, 6 лет).
- **Обучение на первом пациенте:** 6 шагов с наставником, без таймера и баллов.
- **11 микро-уроков:** ошибка открывает разбор «что произошло → почему важно → пример и контрпример → проверь себя» и возвращает на тот же шаг.
- **Зачёт:** тот же кейс без наставника; порог 75/100; результат сохраняется отдельно по каждому кейсу.
- **Шпаргалка и библиотека микро-уроков:** доступны до, во время и после приёма.
- **Карта симптомов в дебрифе:** что подтверждено, что сохранено, что исключено.
- **Прогресс:** навыки, бейджи, история; localStorage.
- **PWA-манифест и service worker:** можно добавить на домашний экран; офлайн — после первого визита.
- **Мобильный интерфейс:** 390×844 — основной сценарий; есть адаптив для планшета и десктопа.

## Что отдавать тестировщику

- **`priem-dist.zip`** или папка `dist/` — только production-сборка: HTML, JS, CSS, manifest, иконка, service worker. Ни исходников, ни кэшей, ни ключей.
- **`priem-source.zip`** — чистый исходник без `node_modules`, `.npm-cache`, `.pw-browsers`, `.bin` и скриншотов.
- **Не отдавайте весь workspace целиком:** там лежат `node_modules`, браузеры Playwright, npm-кэш, бинарник cloudflared и тестовые скриншоты. Секретов в них нет, но это лишний объём и лишний шум.

Перед публикацией проверено: в `dist`, `priem-dist.zip` и исходниках нет `.env`, приватных ключей, API-токенов, паролей и `.npmrc`. Vite не встраивает переменные окружения, кроме `VITE_*`, а их в проекте нет.

## Правило сокращений

При первом упоминании в тексте даём полную расшифровку, дальше — сокращение:

> общее недоразвитие речи (ОНР), фонетико-фонематическое недоразвитие речи (ФФНР), Международная классификация болезней 10-го пересмотра (МКБ-10).

Все сокращения и термины собраны в **Словаре** (40 статей): кнопка «Словарь» в шапке, вкладка «Теория → Словарь» и кнопка в обучении.

## Публикация на GitHub Pages

### Быстрый вариант: один `index.html`

1. Создай **публичный** репозиторий, например `priem`.
2. Загрузи в корень файл `github-pages/index.html` (это single-file сборка; переименуй в `index.html`, если нужно).
3. Settings → **Pages** → Build and deployment → Source: **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)` → Save.
5. Через 1–2 минуты сайт будет доступен: `https://<username>.github.io/priem/`.

В этой сборке JS и CSS внутри одного файла, поэтому путь `/priem/` не ломает ассеты.

### Полный вариант: репозиторий + GitHub Actions

1. Создай пустой публичный репозиторий `priem`.
2. В папке проекта:

```bash
git remote add origin https://github.com/<username>/priem.git
git branch -M main
git push -u origin main
```

3. Settings → Pages → Source: **GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` соберёт проект с `VITE_BASE=/priem/` и опубликует `dist`.
5. Сайт: `https://<username>.github.io/priem/`.

Если репозиторий приватный, GitHub Pages может требовать платный план — для бесплатного теста делай публичный.

## Границы

Это учебный тренажёр алгоритма и дифференциальной логики. Он **не ставит клинический диагноз**,
не заменяет супервизию и живую практику, не используется для скрининга реальных детей. Все кейсы
синтетические; совпадения случайны.
